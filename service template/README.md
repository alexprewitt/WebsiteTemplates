# Summit Local Services Template

This folder contains a reusable, single-page small-business website template built with HTML5, CSS3, Bootstrap 5, and lightweight vanilla JavaScript.

## Files

- `index.html` – complete website structure
- `css/variables.css` – theme variables and Bootstrap overrides
- `css/styles.css` – custom styling and layout rules
- `js/config.js` – optional site settings
- `js/main.js` – minimal functionality for navigation, back-to-top, and the demo contact form
- `assets/` – SVG placeholder images and logo files
- `sections/README.md` – guidance for adding, removing, and reordering sections
- `CUSTOMIZATION.md` – step-by-step customization instructions

## Quick start

Open `index.html` directly in a browser or serve the folder with a lightweight static server if preferred.

## Notes

- The default business name, contact details, and text are placeholder content.
- The contact form is intentionally demo-only and does not submit to a real inbox.
- All testimonials are clearly marked as fictional placeholder content.
- The template is designed for easy reuse across service businesses and local professional brands.
