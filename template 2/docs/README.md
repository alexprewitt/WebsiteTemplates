# Apex Professional Services Template

This project is a premium, reusable static website template for a professional services or contracting business. It is built with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript, and includes a transparent rule-based chatbot designed to support lead-generation goals.

## Features

- Premium business landing page
- Responsive single-page layout
- Sticky navigation and smooth scrolling
- Service cards and industry coverage sections
- Filterable project gallery with modal lightbox
- FAQ accordion and quote request form
- Floating browser-based customer assistant
- Accessible design and keyboard-friendly interaction

## Local setup

1. Open `index.html` directly in a browser, or
2. Serve the folder with a local static server from the project root, for example:
   `python -m http.server 8000`

## Project structure

- `index.html` — main page markup
- `css/` — variables, theme styles, and chatbot styles
- `js/` — site behavior and chatbot logic
- `docs/` — customization and deployment guidance
- `favicon.svg` — site icon

## Important limitations

- This is a static demonstration website.
- Quote forms are intentionally non-submitting unless connected to a real backend or verified form service.
- The chatbot is rule-based only and does not claim to be a generative AI system.
