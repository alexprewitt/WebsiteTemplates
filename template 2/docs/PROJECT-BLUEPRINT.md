# Project Blueprint

## Target audience

Homeowners, property managers, and commercial clients looking for dependable contracting and professional service support.

## Business goals

- Generate qualified quote requests
- Establish trust and professionalism
- Explain services clearly
- Showcase example work
- Encourage direct contact and consultation

## Sitemap

- Home
- About
- Services
- Projects
- Process
- Reviews
- FAQ
- Quote request
- Contact

## Visual identity

- Deep navy primary palette
- Orange accent color
- Clean editorial typography
- Professional and modern layout with generous whitespace

## Chatbot strategy

- Rule-based responses
- Quick replies and section navigation
- Honest fallback when information is unavailable
- No false claims about AI, human staff, or live support

## Technical architecture

- Static HTML/CSS/JS
- Bootstrap for layout and components
- Vanilla JS for interaction logic
- Local knowledge base for the browser assistant

## Risks and tradeoffs

- Keep tone premium without adding heavy visual clutter
- Avoid unsupported business claims
- Keep the chatbot transparent, lightweight, and easy to maintain
