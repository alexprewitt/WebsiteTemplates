# Reusable Components

This template is structured around modular sections that can be reused for other service businesses.

## Core sections

- Header and branded top bar
- Sticky navigation
- Premium hero section
- Trust indicators
- About section
- Service cards
- Industry coverage grid
- Why Choose Us features
- Portfolio gallery with filters and modal
- Process timeline
- Team placeholder cards
- Testimonials
- FAQ accordion
- Quote request form
- Contact panel
- Footer
- Floating chatbot

## Reuse guidance

To adapt the template for a new business:

1. Replace text content in `index.html`
2. Update the colors in `css/variables.css`
3. Edit service labels and chatbot knowledge in `js/chatbot-knowledge.js`
4. Swap or replace hero and project imagery with client-specific assets
