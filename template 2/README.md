# The Grooming Studio Website Template

This project is a premium boutique grooming studio template built as a static, responsive single-page website.

## Stack

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript

## Included sections

- Announcement bar
- Branding header
- Sticky navigation
- Premium hero
- Hair and pet service selectors
- About section
- Haircut services
- Pet grooming services
- Why choose us
- Gallery with filters and modal
- Before-and-after comparison slider
- Team
- Testimonials
- FAQ
- Booking form
- Contact section
- Footer with back-to-top

## Setup

Open `index.html` directly in a browser, or run a local static server from this folder.

## Customization

See `documentation/CUSTOMIZATION.md` for branding, service, gallery, and booking guidance.
