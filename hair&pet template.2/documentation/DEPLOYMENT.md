# Deployment Guide

This website is a static HTML/CSS/JS template, so it can be hosted on almost any static web host.

## Recommended hosts

- GitHub Pages
- Netlify
- Vercel
- Any standard static hosting provider

## Deployment steps

1. Upload the entire project folder to the host.
2. Make sure `index.html` is in the root of the published site.
3. Keep all CSS, JS, and asset folders in place.
4. Verify all relative paths still work after deployment.
5. Test on mobile and desktop before launch.

## Prelaunch checklist

- Placeholder information removed or verified
- Price examples confirmed or removed
- Team profiles replaced with real staff if needed
- Testimonials verified or removed
- Booking system connected or clearly labeled as demo-only
- Contact details tested
- Legal pages completed
- Mobile responsiveness checked
- Accessibility reviewed
- SEO metadata customized
- HTTPS enabled by host
