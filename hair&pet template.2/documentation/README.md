# The Grooming Studio Template

This folder contains a premium, responsive grooming studio website template built with HTML5, CSS3, Bootstrap 5, and lightweight vanilla JavaScript.

## Included files

- `../index.html` – full single-page website structure
- `../css/variables.css` – CSS variables and Bootstrap overrides
- `../css/styles.css` – all custom styling and layout rules
- `../css/animations.css` – subtle reveal animations and reduced-motion handling
- `../js/config.js` – optional site settings for behavior
- `../js/main.js` – interactivity such as filtering, scroll reveals, booking demo, and back-to-top
- `../assets/` – local SVG placeholders for images and branding
- `../favicon.svg` – default site icon

## Quick start

Open `index.html` directly in a browser, or serve the folder with a simple static server.

## Notes

- All business details are intentionally placeholder content.
- The booking form is a demonstration only and does not submit to a real system.
- Testimonials are fictional placeholders and should be replaced or removed before launch.
- The design is modular and can be adapted to hair-only, pet-only, or combined grooming businesses.
